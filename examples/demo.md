## Executive Summary

> [!info] About the dataset
> The Palmer Penguins dataset contains morphological measurements from three penguin species observed near the Palmer Station in Antarctica. It is a modern, drop-in replacement for the classic Iris dataset — with the added benefit of being adorable.

```quack
caption="Dataset overview"
SELECT
  COUNT(*) AS total_penguins,
  COUNT(DISTINCT species) AS species_count,
  COUNT(DISTINCT island) AS island_count,
  ROUND(AVG(body_mass_g), 1) AS avg_mass_g,
  ROUND(AVG(flipper_length_mm), 1) AS avg_flipper_mm
FROM penguins
```

## 1. Species Overview

> [!note] Three species, three islands
> Adelie penguins are found on all three islands, while Chinstrap and Gentoo each occupy a single island. This geographic isolation is a natural experiment in speciation.

### 1.1 Population by species

```quack
chart=bar caption="Penguin counts by species" { "x": "species", "y": "count", "color": { "scheme": "tableau10", "legend": true } }
SELECT species, COUNT(*) AS count
FROM penguins
GROUP BY species
ORDER BY count DESC
```

### 1.2 Average measurements by species

> [!hint] Hover over bars
> Tooltips are enabled by default. In the rendered view you can hover to see exact values.

```quack
chart=bar caption="Average body mass (g) by species" { "x": "species", "y": "avg_mass", "color": { "scheme": "tableau10", "legend": true } }
SELECT species, ROUND(AVG(body_mass_g), 1) AS avg_mass
FROM penguins
GROUP BY species
ORDER BY avg_mass DESC
```

## 2. Morphology Analysis

> [!info] Bill length vs. bill depth
> These two measurements are the classic diagnostic features for distinguishing penguin species. Adelie and Chinstrap cluster by bill depth, while Gentoo separates cleanly by length.

### 2.1 Bill dimensions scatter

```quack
chart=dot caption="Bill length vs. bill depth, coloured by species" { "x": "bill_length_mm", "y": "bill_depth_mm", "stroke": "species", "color": { "scheme": "tableau10", "legend": true }, "tip": true }
SELECT bill_length_mm, bill_depth_mm, species
FROM penguins
WHERE bill_length_mm IS NOT NULL AND bill_depth_mm IS NOT NULL
```

> [!tip] Notice the clustering
> The three species form distinct clusters. This is why bill dimensions alone are enough for a highly accurate classifier.

### 2.2 Flipper length distribution

```quack
chart=boxY caption="Flipper length distribution by species" { "x": "species", "y": "flipper_length_mm", "fill": "species", "color": { "scheme": "tableau10", "legend": true } }
SELECT species, flipper_length_mm
FROM penguins
WHERE flipper_length_mm IS NOT NULL
```

### 2.3 Body mass vs. flipper length

> [!note] Size matters
> Gentoo penguins are substantially larger than the other two species — both in body mass and flipper length. The point radius here is mapped to bill depth, adding a third dimension.

```quack
chart=dot caption="Body mass vs. flipper length, sized by bill depth" { "x": "flipper_length_mm", "y": "body_mass_g", "stroke": "species", "color": { "scheme": "tableau10", "legend": true }, "r": "bill_depth_mm", "tip": true }
SELECT flipper_length_mm, body_mass_g, bill_depth_mm, species
FROM penguins
WHERE flipper_length_mm IS NOT NULL AND body_mass_g IS NOT NULL
```

## 3. Island Geography

> [!info] Island metadata
> The three islands differ dramatically in size. Torgersen is tiny (just 0.1 km²), while Biscoe spans 56 km². Does island size correlate with penguin mass?

### 3.1 Island reference data

```quack
caption="Island reference data"
SELECT * FROM islands ORDER BY area_km2 DESC
```

### 3.2 Penguin density by island

```quack
chart=bar caption="Penguins per island" { "x": "island", "y": "count", "color": { "scheme": "spectral", "legend": true } }
SELECT island, COUNT(*) AS count
FROM penguins
GROUP BY island
ORDER BY count DESC
```

### 3.3 Average mass by island area

> [!hint] No clear correlation
> Despite the dramatic difference in island sizes, average body mass is remarkably consistent across islands. What matters is species, not geography.

```quack
chart=dot caption="Island area vs. average penguin mass" { "x": "area_km2", "y": "avg_mass", "stroke": "island", "color": { "scheme": "spectral", "legend": true }, "tip": true }
SELECT
  i.island,
  i.area_km2,
  ROUND(AVG(p.body_mass_g), 1) AS avg_mass
FROM penguins p
JOIN islands i ON p.island = i.island
GROUP BY i.island, i.area_km2
ORDER BY i.area_km2 DESC
```

## 4. Sexual Dimorphism

> [!note] Males are heavier
> Across all three species, males are consistently heavier than females. The difference is most pronounced in Gentoo penguins.

### 4.1 Mass by sex and species

```quack
chart=bar caption="Average body mass by species and sex" { "x": "species", "y": "avg_mass", "fill": "sex", "color": { "scheme": "pastel1", "legend": true } }
SELECT species, sex, ROUND(AVG(body_mass_g), 1) AS avg_mass
FROM penguins
WHERE sex IS NOT NULL
GROUP BY species, sex
ORDER BY species, sex
```

### 4.2 Faceted body mass distribution

> [!tip] Faceting in one line
> The `fx` option splits the chart into small multiples. Here we facet by sex to see the distribution side-by-side.

```quack
chart=boxY caption="Body mass distribution by species (faceted by sex)" { "x": "species", "y": "body_mass_g", "fx": "sex", "fill": "species", "color": { "scheme": "tableau10", "legend": true } }
SELECT species, sex, body_mass_g
FROM penguins
WHERE sex IS NOT NULL
```

## 5. Correlation Matrix

> [!info] Pearson correlations
> DuckDB's `CORR()` function computes Pearson correlation coefficients. Flipper length and body mass are strongly correlated (r ≈ 0.87), which is expected — larger penguins need larger flippers.

```quack
caption="Correlation matrix of morphological traits"
SELECT
  ROUND(CORR(bill_length_mm, bill_depth_mm), 3) AS bill_len_depth,
  ROUND(CORR(bill_length_mm, flipper_length_mm), 3) AS bill_len_flipper,
  ROUND(CORR(bill_length_mm, body_mass_g), 3) AS bill_len_mass,
  ROUND(CORR(bill_depth_mm, flipper_length_mm), 3) AS bill_depth_flipper,
  ROUND(CORR(bill_depth_mm, body_mass_g), 3) AS bill_depth_mass,
  ROUND(CORR(flipper_length_mm, body_mass_g), 3) AS flipper_mass
FROM penguins
```

> [!hint] Strongest correlation
> The strongest relationship is between **flipper length** and **body mass** (0.87). The weakest is between **bill length** and **bill depth** (0.23), which makes sense — these are the features that *separate* species rather than scale together.
